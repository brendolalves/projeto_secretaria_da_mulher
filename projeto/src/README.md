# Código-fonte

- `coleta/`: baixa as internações, a malha municipal e a fonte de bairros do IBGE.
- `processamento/`: georreferencia a base e extrai bairros da malha baixada.
- `visualizacao/`: gera o mapa HTML interativo.

Os scripts calculam a raiz do projeto automaticamente; podem ser executados de qualquer diretório.
